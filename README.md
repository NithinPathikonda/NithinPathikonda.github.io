## 🌟 Highlights & Design Principles

1. **DeveloperFolio Signature Features**:
   - **Hero Section & Dynamic Role Rotator**: Typewriter effect showcasing SDE 1, Go microservices, and Agentic AI expertise.
   - **Interactive Theme Switcher**: Instant Dark Mode / Light Mode with system preference detection and `localStorage` persistence.
   - **What I Do (3 Core Pillars)**:
     - High-Throughput Microservices & Distributed Systems
     - Agentic AI & Model Context Protocol (MCP)
     - Cloud Native, Container Orchestration & DevOps
   - **Technical Skills Matrix**: Tagged chips across Languages, Backend, AI/Agents, Cloud/DevOps, Databases, and MLOps.
   - **Work Experience Timeline**: Hewlett Packard Enterprise SDE 1 and Intern roles with verified metrics (100K+ daily executions, sub-50ms latency, 99.2% reliability, 15+ hrs/week toil eliminated).
   - **Featured Projects & Case Studies**: Tom Scott-inspired case study structure (Problem -> Solution -> Impact -> Badges -> Links) featuring `Pro_resume`, `MCP Data Bridge`, `Enterprise Dgraph Knowledge Graph`, and `ITSM Classifier`.
   - **Academic Honors**: JSS Science & Technology University (BE ISE, GPA: 9.60 / 10.0, Ranked Top 3 in Department).
   - **Interactive Reach Out**: One-click email copy, social media pills, and an instant message drawer.

2. **Performance & Clean Architecture**:
   - Zero framework overhead — pure semantic HTML5, modern vanilla CSS3 with CSS variables, and modern JavaScript.
   - 100% responsive across mobile, tablet, and widescreen desktops.
   - Ultra-fast load times (< 100ms) with zero build steps required.

## 🚀 Quickstart & Local Preview

### Option 1: Direct Browser File Preview
Simply open `index.html` in your browser:
```bash
open /Users/nithinpathikonda/Documents/Portfolio/portfolio-website/index.html
```

### Option 2: Run via Local Python Server
```bash
cd /Users/nithinpathikonda/Documents/Portfolio/portfolio-website
python3 -m http.server 3000
```
Open **[http://localhost:3000](http://localhost:3000)** in your browser.

### Option 3: Run via Pro_resume FastAPI Web Studio
```bash
cd /Users/nithinpathikonda/Documents/Portfolio
python3 tailor.py --web
```
Visit **[http://localhost:8000/portfolio](http://localhost:8000/portfolio)**.

## 🌐 Free 1-Click Hosting / Deployment

### GitHub Pages (Recommended)
1. Push this folder to a GitHub repository named `NithinPathikonda.github.io` (or your existing repo).
2. Go to **Settings > Pages > Source** and select `Deploy from a branch` (e.g. `main` or `/portfolio-website`).
3. Your portfolio goes live instantly at `https://nithinpathikonda.github.io`!

### Vercel / Netlify
- Drag and drop the `portfolio-website` folder onto [Netlify Drop](https://app.netlify.com/drop) or import from GitHub on Vercel for instant free global CDN hosting.
